# Product Requirements — המטבח הצרפתי

## Goal
A mobile-first, Hebrew RTL recipe web application showcasing authentic French cuisine. Zero build step, deploys to GitHub Pages.

## Features (V1)
- [x] 10 authentic French recipes in Hebrew
- [x] 5 categories: מרקים, מנות עיקריות, מאפים ולחמים, קינוחים, רטבים ותוספות
- [x] Real-time search with 200ms debounce
- [x] Category filter pills
- [x] Recipe detail view with ingredients and step-by-step instructions
- [x] WhatsApp shopping list sharing
- [x] Responsive grid (1→3 columns)
- [x] Glassmorphism + card-lift design system
- [x] Hash-based SPA routing

## Design
- **Palette**: Burgundy (#8B1A1A), Warm Tan (#C4A484), Deep Burgundy (#6B1010)
- **Aesthetic**: Luxury minimalist with French culinary elegance
- **Typography**: Heebo (Hebrew body), Playfair Display (titles)
